# NexoWatt EOS Admin Standalone Adapter

Diese Version trennt die EOS-Oberfläche vom offiziellen ioBroker `admin` Adapter.

- technischer Adapter: `eos-admin`
- npm-Paket: `iobroker.eos-admin`
- Instanz: `eos-admin.0`
- Standard-Port: `8081`

Der alte `admin.0` kann parallel laufen. Für den finalen Betrieb kann `admin.0` gestoppt und `eos-admin.0` auf Port `8081` gesetzt werden.
