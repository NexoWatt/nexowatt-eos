# Installationstest 7.10.4

1. Version 7.10.4 installieren und EOS Admin starten.
2. Mindestens 60 Sekunden prüfen, dass kein Start-/Stop-Loop auftritt.
3. Übersicht und Module öffnen: Die Karte **Automatische Adapter-Updates** darf dort nicht sichtbar sein.
4. Schraubenschlüssel öffnen: Die Karte muss direkt unter der Kopfleiste der Systemeinstellungen erscheinen.
5. Schalter einmal deaktivieren und wieder aktivieren; Status und Repository müssen weiter angezeigt werden.
