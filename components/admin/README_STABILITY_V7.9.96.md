# NexoWatt EOS Admin 7.9.96 – Stabilität

Diese Version übernimmt den vollständigen Stand 7.9.95 sowie die EMS-LIVE-DIAGNOSE-Merge-Dateien. Sie korrigiert die Anmeldekarte, die erste persönliche Kennwortvergabe und die rollenabhängige Übersicht.

- Native Admin-Übersicht für Admin, Installateur und Endkunde
- Read-only EMS-Kachel aus `nexowatt-ui.*.info.adminOverview.*`
- Technische Details für Admin/Installateur, reduzierte Erklärung für Endkunden
- Größere Login-Karte ohne interne Scrollbalken
- Erstkennwort `nexowatt` führt zwingend zur persönlichen Kennwortvergabe
- Interner Admin und interne BackItUp-Reserve bleiben für Nicht-Admins verborgen
- EOS Assist bleibt deaktiviert
