# NexoWatt EOS Admin 7.9.94

Stable Verkaufsprodukt-Version. Diese Version übernimmt die Bedien-, Rollen- und Login-Korrekturen aus 7.9.91 und härtet die Release-Vorbereitung.

Vor Paketprüfung und Veröffentlichung werden folgende verbindliche Standardwerte automatisch gesetzt:

- Authentifizierung aktiv
- EOS Admin Standardport 8081
- interner Admin nur für Admin/Service
- interne BackItUp-Notfallreserve nur für Admin/Service
- NexoWatt-Backup-Sichtbarkeitskompatibilität aktiv
- Erstpasswort-Pflicht aktiv

Die Normalisierung verändert keine bestehenden Kundendaten auf einem installierten System; sie betrifft die Paketmetadaten des zu veröffentlichenden Adapters.
