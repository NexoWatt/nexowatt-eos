# RC69-Feldtest-Checkliste – Ladepunkt-Feedback

- [ ] Im Dashboard unter **Systemstatus** werden nur aktive Ladepunkte angezeigt.
- [ ] Ladepunkt ohne Fahrzeug zeigt „Kein Fahrzeug verbunden“.
- [ ] Aktive Ladung zeigt Istleistung und Modus.
- [ ] PV-Modus ohne Überschuss zeigt „Wartet auf PV-Überschuss“.
- [ ] Zeit-Ziel-Wartephase zeigt Ziel-Laden und Zielzeit beziehungsweise den Planungsgrund.
- [ ] Tarifpause zeigt den aktuellen Tarifgrund.
- [ ] §14a-Kommunikationsfallback zeigt Warnung und wirksames Fallbackbudget.
- [ ] Ein echter EOS-Safety-Stopp zeigt roten Status und verständlichen Grund.
- [ ] Offline-, Fehler-, RFID- und Mappingzustände werden korrekt unterschieden.
- [ ] Nicht bestätigter Wallboxbefehl wird als Fehler angezeigt.
- [ ] Der Link **Details** öffnet das Lademanagement.
- [ ] Deutsch/Niederländisch wechseln ohne veraltete Texte.
- [ ] Lade-, Speicher-, §14a- und Safety-Regelung verhalten sich gegenüber RC68 unverändert.
