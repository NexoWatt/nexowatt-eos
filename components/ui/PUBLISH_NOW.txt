NexoWatt UI 1.0.21 – OFFICIAL STABLE RELEASE

Vollständiges Repository: übersichtliche Nulleinspeisung und geschützte SmartHome-Einrichtung.

Installateure und Administratoren zugänglich; Kunden erhalten keine DP-Zuordnung.

Keine Prüfung echter Anlagenhardware im automatisierten Release-Test.
Details: docs/STABLE_1_0_21_RELEASE_DE.md

Das normale npm publish --tag latest bereitet alte Admin-Bundles automatisch vor:
Sicherheitsprüfung, bestätigter aktueller Build, Sicherung unbenutzter Altdateien
außerhalb des Projekts, danach die unverändert strengen Release-Prüfungen.
Aktuelle Bundles, Produktquellen und Einstellungen werden nicht verändert.
Echte Sicherheitsfunde blockieren weiterhin. Keine automatische Neuversiegelung.

Lokale Vorprüfung: npm run release:prepare und npm run publish:check
Gesamte Prüfung: npm run release:check
Bei Git-Verwendung entfernte alte Dateien vor dem Commit mit erfassen:
git add -u -- admin/react/assets
Der Sicherungspfad wird ausgegeben. Keine automatische Änderung des Git-Index.

Vollständigen Release übernehmen, einschließlich package.json, scripts und admin/react.
Neue Versionsnummer erst veröffentlichen, wenn der npm-Versionsguard sie freigibt.
Diese ZIP führt selbst keine Veröffentlichung und keine Live-Hardwaretests aus.
