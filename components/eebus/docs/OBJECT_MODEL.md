
## Ack rules

- Values received from EEBUS or generated by the adapter are written with `ack: true`.
- User commands are received with `ack: false`.
- Button states are reset to `false` with `ack: true` after handling.
- Write commands are stored in `raw.lastCommand` before being sent.
- In dry-run mode, write commands are not sent but remain visible in `raw.lastCommand`.
